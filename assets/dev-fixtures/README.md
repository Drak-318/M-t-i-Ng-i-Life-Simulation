# Development-only GLB fixture

The asset lab downloads the Quaternius Universal Base Characters Superhero Male sample from the pinned upstream repository commit recorded in assets/characters/manifest.json.

- Author: Quaternius
- Source pack: https://quaternius.com/packs/universalbasecharacters.html
- License: CC0 1.0 Universal
- License text: QUATERNIUS-LICENSE.txt
- Purpose: test GLB loader, skinned mesh, skeleton inspection and scale normalization.
- Restriction within this project: this is not an approved visual asset for Minh, Linh or background NPCs.

The GitHub Pages workflow downloads this fixture into its temporary deployment artifact. The binary is intentionally not stored in the production asset manifest.
